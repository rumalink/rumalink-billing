⚠ Reset to Production

Wipes all test data — ISPs, payments, vouchers, sessions, devices, RADIUS. Keeps your admin login, IntaSend/Daraja keys, and fee/commission settings. A full database backup is saved before anything is deleted. This cannot be undone except by restoring that backup.

↩ Restore from Backup

Replaces the entire database with a saved backup. Everything created since that backup is lost. A snapshot of the current state is saved first, so this is undoable.

Admin Account

🏦 Equity Bank (Jenga) — Collection Provider

Your single platform Jenga / Finserve credentials. Used to collect M-Pesa STK payments that settle directly into each ISP's own Equity account (you never hold the funds). Secrets are write-only — saved values show as a placeholder; leave a field blank to keep the stored value.

📱 Safaricom Daraja (M-Pesa STK) — Platform Fallback

Platform M-Pesa Daraja credentials, used as the fallback STK rail for PPPoE self-service payments when an ISP has not configured their own M-Pesa. Secrets are write-only — saved values show as a placeholder; leave blank to keep the stored value.
